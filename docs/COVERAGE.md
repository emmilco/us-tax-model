# Coverage reference

Generated by `tools/coverage/tree.py` from the tax year 2025 form data, the coverage estimate and `tools/coverage/tree.json`; do not edit by hand. `check-all` fails when a refusal gate is missing here, when a gate listed here is gone from the forms, or when this page or the README table is out of date.

Start with the coverage table in the [README](../README.md#where-the-scope-runs-out): if nothing in its right-hand column applies to you, the tool should be able to prepare your return. This page is the reference behind that table: every situation the tool refuses, with the wording the data uses, the forms it names, the remedy the tool prints and the archived IRS source.

## What the table leaves to the interview

The table is built to be nearly right for nearly everyone in one look, not to list everything. Every refused situation the coverage estimate measures at 0.5% of returns or more is in it (the check enforces that), along with a few situations the estimate cannot measure but that are common enough to name. Everything else is left to the interview, which asks about every situation below and, if one applies, stops and cites the instruction behind it.

Measured, below 0.5% of returns, and not in the table:

- Household employment, uncollected tip taxes, homebuyer credit repayment: 0.4%
- Foreign earned income exclusion (Form 2555): 0.3%
- Alternative minimum tax: 0.1%

Not named in the table: 149 of the 157 situations the tool refuses. Most are rare, and most are not measured; the coverage estimate has an IRS count for only a handful of situations, so the table's choice of unmeasured ones is a judgment.

The estimate puts coverage at 78.4% of returns (`reports/2025/filer_coverage.json`). It does not count the unmeasured situations, so the true figure is lower.
