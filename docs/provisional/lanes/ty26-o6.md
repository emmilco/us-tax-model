## Decisions

1. **`s2.line1a` written by this lane** (in a split file per D3). Removing `f8962.line29` leaves the read dangling
   otherwise, and the check would fail. Lane O1 owns Schedule 2; if O1 also sets `s2.line1a expr.alternatives`, the
   check reports a collision at merge; keep one. Only `expr.alternatives` is set; the cite (i1040gi, "Form 8962,
   line 29") is left, as it waits for the 2026 i1040gi.
2. **Locator pages are archive (PDF) pages**, as the evidence is: the 2026 i8889 and f8962 drafts carry a cover
   page, so every i8889 page is the printed page plus one. When the finals replace the drafts, those locators move
   back by one (the flip lane F2, or the cover-aware relocation, must cover op-written values).
3. **C-PEOP-27 is one question per return**, not per Form 1095-A: the refusal is whole-return either way, and it sits
   with the other Marketplace refusals. Its refusal is told through `f8962.other`'s existing remedy on lines 24/25,
   which is not extended: `f8962.line24` defines the YAML anchor its refusal list is aliased by (see the defect below).
4. **Year literals** are set only in fields an operation sets anyway; other 2025 wording is left to adoption's
   literal list.
