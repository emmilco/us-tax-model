## Tools (this directory)

- `m3/mutate_subset.mjs`: runs the mutants whose location is in the named documents, judged as `mutate.ts` judges them
  (checker, then every federal fixture), and prints each survivor no argument explains. Not a substitute for
  `node engine/dist/main.js mutate` (no self-tests, no staleness check).
- `m3/gen_table.py` writes `m3/cases.json` (one row per case: base case, inputs set and dropped, predicted values);
  `m3/gen_cases.mjs` evaluates each row, stops on any prediction the evaluator does not give, and merges the cases by
  id into `fixtures/2025/mutation.json` (kept as `json.dumps(indent=2, ensure_ascii=False)` plus a newline).

## Convention for unasked questions

A case may leave a question unanswered when the interview would not ask it of that filer (its gate is No). That is
what kills a mutant that widens a gate: the baseline never reads the question, the mutant does and is unknown.
