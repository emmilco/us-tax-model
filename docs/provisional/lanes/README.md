# Lane notes: records, not guidance

Each `<lane>.md` here is the report an agent lane wrote at the end of its run: what it changed, what it found, what
it left, and what it proposed to the coordinator or the owner. A `<lane>_work/` folder (or `m3/`, `rc_trial/`,
`stitch_trial/`) holds that lane's scratch scripts and outputs.

**These notes are records, not guidance.** A note describes the tree its lane worked on, often a scratch clone or
worktree that has since been merged, changed or discarded. Its "next steps", "decisions" and "rules" are proposals
of that date, not standing instructions. Before relying on a claim in a note, check it against the current tree.
Cite a note as the source of a finding ("lane O5 found ..., `docs/provisional/lanes/ty26-o5.md`"); never cite it as
the reason a rule holds.

Current guidance is in the normative documents named in `CLAUDE.md` and in the current entry of
`HANDOFF-NEXT-SESSION.md`. Decisions are recorded in `CLAUDE.md`, `docs/provisional/DECISIONS.md`, the task rows of
`TASKS.md` and the normative documents themselves, not here.
