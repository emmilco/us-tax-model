### T-316, tool items

1. **Line-scoped catalog lists an interface computed from a reviewed line** (land3-adj2, `div.has_capital_gain`).
   Real. `transcribe.catalog_lines(..., under_review=scope_ids)` leaves out another form's computed line whose
   value is computed (through any lines, any form) from a scoped line, unless the reviewed form reads it (those
   are boundary references `input_context.assess` requires in the prompt). Line-scoped reviews only; see
   "For the coordinator" for the whole-form measurement.
2. **Triage applies only the project's `shown_when`** (land3-adj3, adj6). Real. `triage.py` passes the
   reply's `shown_when` (`candidate_shown_when`); `triage.mjs` applies it to the reply's values as it applies the
   project's. `same` and `difference` moved to `triage_rules.mjs` (pure, tested); a line the reply hides where the
   project shows an amount is the new kind `candidate-hides-shown`; a hidden line agrees with a blank one.
   `POLICY` was not changed (see "For the coordinator").
3. **`rule.py` has no amend step** (land3-adj6). Real. `rule.py --amend` rewrites an applied ruling's text in the
   log and sidecar, keeping class, drop flag, key, context and stamps (date renewed; a finding keeps its severity).
   A change of class or of drop, an open section, a `*` key or a key with no applied ruling is refused.
4. **`siblings.py`**: (a) a field containing the word "none" was read as empty: real; `checked_ids` no longer
   special-cases it (a field naming no id is empty as before). Only one entry in the inventory has the word
   ("None generated ..."), and it names no id, so no current result changes. (b) a fix's own lines counted as
   siblings to list: real; `missing_siblings` removes them. The brief's advice to list own lines and avoid "none"
   is now unnecessary (harmless). The existing exemption (no form of the year changed since the base) is kept,
   factored as `review_logs_due`, with self-test cases.
5. **Class M generator spends cases on refused returns** (land3-adj12, MFS Form 8962). Real.
   `classm-jobs` drops a return the interview refuses (a target of the full interview is a refusal) from every
   document's candidates and every definition's instances.
6. W-2 box 3 always 0 in stage-derived class M person cases (land3-adj13): fixture data (`classm.json`), lane
   T2's scope (corpus restatement), not changed here. `bonus_same` default reason, personas numbered 13, f1095a
   help: not tool items (b5: not meaningful).
