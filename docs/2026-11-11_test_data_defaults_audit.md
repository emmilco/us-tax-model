One row per default in `fixtures/2025/defaults.json` (us) and `fixtures/ny/2025/defaults.json` (ny).

Counts were measured on the tree before T-269's fixture changes. The verdict and basis columns are the audit's own: "FIXED", "NOT FIXED" and "now withhold" in them describe the per-case nulls T-269 added, which T-277 has since replaced.

## What became of the nine untruthful defaults (T-277)

The mechanism is described in `tools/README.md`, "Test-data defaults".

| input | outcome |
|---|---|
| `household.married` | Withheld in the defaults on a joint or separate return (47 federal and 5 New York separate-return cases). The two joint cases whose scenario is a filer not married at the end of the year state the no. |
| `household.unmarried` | Withheld in the defaults for a single filer and a qualifying surviving spouse (841 federal and 83 New York cases). `ss.hoh`, a head of household that stated neither marital answer, states the yes; its return is refused at the head-of-household tests (`household.hoh_fails`) as before. |
| `f1095a.b_counted` | Withheld in the defaults where the return has one Form 1095-A; the 49 per-case nulls are removed. |
| `dependent.edu_tin_issued` | Withheld in the defaults for a student whose answers allow the American opportunity credit; the 6 per-case nulls are removed, and the case whose student's number was only applied for states the no. The two lifetime learning cases are unchanged. |
| `dependent.lawful` | The default is yes; the 10 per-case nulls are removed. |
| `f4952.has_interest` | The three cases that state a line 4g election state yes; a consistency rule refuses the combination. |
| `person.born_before_2001`, `person.edu_born_2002`, `person.edu_born_2007` | Unchanged. Consistency rules state the contradictions and list the defaults themselves and two student cases as open. |

## The audit

- **Cases taking**: fixture cases (class M and mutation files excluded; they take no defaults) in which at least one entry takes the default. New York rows count the New York cases.
- **Returns reading**: of those, the cases in which the whole-return interview targets read the defaulted answer, that is, where the interview would have asked the question.
- **TRUTHFUL**: a coherent answer in the default scenario, read by at least one return, and no case found whose stated facts contradict it.
- **NOT-ASKED**: no case's return reads the default, so the value is never a filer's answer; a reviewer that reads it gets an answer nobody gave.
- **UNTRUTHFUL-FOR-SOME**: named cases whose stated facts contradict the default.
