## usc-* host question: no owner decision needed
`fetch_sources.py` allows www.irs.gov, www.govinfo.gov, www.fincen.gov, www.ssa.gov, www.rrb.gov (no path rule for `us`); uscode.house.gov is not allowed, but the catalog already has `usc-26-179`, `-36b`, `-25a`, `-72`, `-4973`, `-172`, all as govinfo `USCODE-2024-title26` section PDFs. I followed that precedent, so the tool is unchanged and nothing was curled to the nightplan sources folder. The govinfo path needs the subchapter/part/subpart, which I found by trial (the wrong path 302s to /error and returns HTML):
- 402: `...-subtitleA-chap1-subchapD-partI-subpartA-sec402.pdf`
- 457: `...-subtitleA-chap1-subchapE-partII-subpartB-sec457.pdf` (457 is in Subchapter E, not D; the location came from the Cornell LII breadcrumb).
Both returned application/pdf. Their catalog rows use `document_tax_year: 2025` and a `purpose` mentioning BUG-0719, in the style of usc-26-72. Their manifest revision stays at the tool's default (`null`, "Pending inspection...") as for the other usc-* rows; I did not set a revision. Text check: usc-26-402.txt has "§ 402. Taxability of beneficiary of employees' trust" (page header "§ 402"), usc-26-457.txt has "§ 457. Deferred compensation plans of State and local governments..."; page counts 23 and 11 (form feeds). The 2024 edition predates 2025 legislation (the 179 row records this for P.L. 119-21), so any 2025 amendments to 402/457 are not in these PDFs (not checked).
