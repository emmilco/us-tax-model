# Source-based partial-input cases

These engineering checks clarify what an independent transcription must compute when
some input answers are absent. The interview derives questions from the evaluator's
dependencies; copying its authored question guards into a blind request would disclose
part of the implementation. Instead, the request receives synthetic facts derived from
archived primary instructions, with no reference answers or project expressions.

The 2025 dependent bank uses Form 2441 instructions pages 1 and 3 and Publication 503
page 3, pinned to archived text hashes. Ten hand-constructed records cover younger
children, the thirteenth-birthday timing split, older disabled children, and an age-13
case whose timing answer genuinely remains unknown. Expected answers come from those
instructions and stay host-side. They were not copied from generated fixtures, model
replies or authored output values. The authored implementation is checked against the
same bank as a consistency baseline.

`public_prompt` projects only case ids, synthetic inputs and target names. Unit canaries
check that reference answers and host rationale cannot enter that projection. The case
bank's full hash, actual prompt inclusion, policy and result are recorded separately.
Changing the host reference cases invalidates old ruling contexts. A required bank
cannot silently disappear; changed source hashes require case review.

`check_input_contracts.mjs` runs only after the shared expression schema/type checks
pass. It uses the fixed declarative evaluator, not JavaScript supplied by a model.
Model gate ids are adapted to the evaluator's refusal object format and checked as
Bool references. The candidate replaces only the reviewed document in memory; foreign
interfaces remain the host context. Missing computed helpers are not borrowed from the
authored document. Inputs are validated, cases are capped at 32, candidates at 5,000
lines, and the process at a 30-second timeout and 256-MiB V8 old-space setting. No model-generated command, tool, file path,
network request or arbitrary code runs. Candidate math is not patched into agreement.

Reports show each expected and observed result. Invalid candidates are skipped and
cannot pass. An unknown result is preserved when the source facts do not determine an
answer. Old requests without the cases remain labeled absent even if their outputs are
checked diagnostically. Only current passing results with actual request inclusion can
satisfy the applicable qualification gate.

These are finite source/interface examples, not whole-form correctness proofs. They do
not cover every relationship, refusal or credit regime, create numeric fixtures, earn
H/B/M/engine evidence or remove the global transcription hold. Further synthetic cases
and source adjudication remain necessary where an interface is still unclear.

The first draft inherited positive qualified expenses in two nonqualifying cases.
BUG-0136 corrects those records to no current qualified expenses and care=false;
a fact-only regression checks that the same inconsistency cannot recur. The draft
bank and its actual requests/replies remain archived. Corrected requests have a
new bank/prompt hash; draft results are not relabeled as corrected results.

The 2025 HSA bank adds seventeen source cases from i8889 pp.4/7/8/9 and f8889 p.1.
They cover zero/positive distributions, genuine missing follow-ups, supplied excessive
rollovers, mandatory scope screens, a zero contribution and one/two spouse HSAs with
family coverage. Reference amounts are derived directly from those pages. Eight known
money cases also seed ordinary numeric regressions; those fixtures are explicitly
synthetic and earn no independent evidence credit.

`when_known: true` is a generic consistency-check declaration, not a supplied tax rule.
A true gate still refuses and a refused gate propagates. An unanswered check may be
left unperformed only while the expression determines its own value without assumed
answers; the derivation records that distinction and its unused question dependencies
are discarded. Ordinary eligibility/scope gates remain mandatory. Model-declared flags
are syntax/type-checked and preserved, never imported from authored computed lines.

Draft H12 prescribed where the project scope screen should run on intermediate lines.
It now checks only the unknown final results, which the source supports. Twelve draft
artifacts are hashed under the scope-case correction archive; fresh corrected requests
retain their actual hashes and are not relabeled as seeing the later spouse cases.
