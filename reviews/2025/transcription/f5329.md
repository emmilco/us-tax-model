Second transcription's note: Open point. Per 'Who Must File', the form is not required only when code 1 is shown on all Forms 1099-R and the 10% tax is owed on the full amount. Reading chosen: filing is required when (a) an exception is claimed (line 2 > 0), (b) a SIMPLE IRA amount is taxed at 25% (line 4 is then not a plain 10% of the full amount), or (c) there are excess HSA contributions. Wrong codes and partial code-2 exceptions are refused per distribution (retirement.code_screen).

Ruling: representation; i5329 p. 1, Who Must File: "However, if distribution code 1 is correctly shown in box 7 of all your Forms 1099-R and you owe the additional tax on the full amount shown on each Form 1099-R, you don’t have to file Form 5329."; i1040gi p. 112, Line 8, Exception: "But you must file Form 5329 if distribution code 1 is incorrectly shown in box 7 of Form 1099-R or you qualify for an exception". Both lines say the form is required for an exception, a code S amount or 2025 HSA excess. The candidate tests line 2 after the per-person limits, the code S part of line 3 and line 47; the project tests the exception amounts before the limits, code S line 1 amounts and line 48. They differ only where every claimed exception is limited to $0 (for example exception 05 with Schedule A line 4 at $0), or a code S distribution is wholly excepted; the tax is the same either way, and filing a form with an exception claimed is what p. 112 asks of a filer who claims one.
